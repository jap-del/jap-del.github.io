클릭 속도·기억력 테스트 개발기: 공정한 측정과 공정한 출제

개발기2026년 11월 12일 · 게임 허브

클릭 속도 테스트와 숫자 기억력 테스트는 규칙이 단순한 만큼, 측정이 공정한지가 게임의 전부입니다. 두 게임을 만들며 고민한 부분을 정리했습니다.

클릭 속도 테스트

click이 아니라 pointerdown

브라우저의 click 이벤트는 버튼을 눌렀다가 뗄 때 발생합니다. 빠른 연타에서는 누르고 떼는 사이의 시간이 그대로 지연이 되고, 스마트폰에서는 터치 후 지연이 더해지기도 합니다. 그래서 누르는 순간 바로 발생하는 pointerdown으로 셉니다. 마우스와 터치를 같은 코드로 처리할 수 있다는 장점도 있습니다.

area.addEventListener('pointerdown', function(e){
  if(e.pointerType === 'mouse' && e.button !== 0) return; // 왼쪽 버튼만
  e.preventDefault(); hit(e);
});

스마트폰에서 두 손가락으로 번갈아 탭하면 손가락마다 pointerdown이 따로 오기 때문에 자연스럽게 각각 셉니다. 반대로 키보드는 세지 않습니다. 키를 꾹 누르고 있으면 운영체제가 자동으로 반복 입력을 만들어 공정한 비교가 어렵기 때문입니다.

시간은 첫 클릭부터

"시작" 버튼을 누르고 나서 클릭 영역으로 손을 옮기는 시간까지 기록에 들어가면 억울하겠죠. 그래서 클릭 영역을 처음 누르는 순간을 0초로 잡습니다. 시간은 라이트 아웃과 마찬가지로 performance.now()로 재고, 클릭할 때마다 시작 시점과의 차이를 배열에 저장합니다. 측정 시간이 끝난 뒤 들어온 클릭은 버립니다.

끝난 직후에는 약 1초 동안 입력을 막습니다. 마지막 연타의 관성으로 다음 판이 의도치 않게 시작되는 것을 막기 위해서입니다.

구간별 속도 그래프

클릭 시각을 모두 저장해 두었기 때문에 끝난 뒤에 구간별 속도를 계산할 수 있습니다. 5초 모드는 1초씩 5칸, 1초 모드는 0.2초씩 5칸, 30초 모드는 3초씩 10칸으로 나눕니다.

var w = sec * 1000 / bins;              // 한 칸의 길이(ms)
times.forEach(function(t){
  cnt[Math.min(bins - 1, Math.floor(t / w))]++;
});
var rate = cnt.map(function(c){ return c / (w / 1000); }); // 칸별 CPS

앞쪽 절반과 뒤쪽 절반의 클릭 수를 비교해 "후반 속도 변화"도 보여 줍니다. 대부분 마이너스가 나오는데, 이 숫자가 0에 가까울수록 끝까지 일정한 리듬을 유지했다는 뜻입니다.

숫자 기억력 테스트

너무 쉬운 문제 거르기

숫자를 완전히 무작위로 뽑으면 가끔 "5555"나 "0012" 같은 문제가 나옵니다. 같은 숫자가 이어지면 기억하기 쉬워지고, 첫 자리 0은 입력할 때 헷갈립니다. 그래서 두 가지 규칙을 넣었습니다.

do { d = Math.floor(Math.random() * 10); }
while(d === prev || (i === 0 && d === 0));  // 연속 숫자 금지, 첫 자리 0 금지

보여 주는 시간

자릿수가 늘면 읽는 데도 시간이 더 필요합니다. 보여 주는 시간은 800 + 400 × 자릿수(ms)로 정했습니다. 3자리는 2초, 7자리는 3.6초입니다. 너무 길면 외울 시간이 넉넉해져 테스트의 의미가 줄고, 너무 짧으면 읽기 속도 테스트가 되어 버립니다. 여러 번 직접 해 보며 맞춘 값입니다.

숫자를 보여 주는 도중 다른 탭으로 가면 그 문제는 취소하고, 돌아왔을 때 같은 자릿수의 새 숫자를 다시 보여 줍니다. 탭을 옮겨 시간을 버는 일을 막기 위해서입니다.

모바일 키보드 대신 직접 만든 키패드

처음에는 일반 입력창을 썼는데, 스마트폰에서 문제가 두 가지 있었습니다. 시스템 키보드가 올라오면서 화면을 가리고 페이지가 밀리는 문제, 그리고 숫자가 사라지는 순간 입력창에 자동으로 커서를 두어도 기기에 따라 키보드가 바로 뜨지 않는 문제입니다.

그래서 화면 아래에 숫자 키패드를 직접 만들었습니다. 버튼 12개(0~9, 지우기, 확인)를 pointerdown으로 처리하고, PC에서는 같은 함수를 키보드 숫자 키, Backspace, Enter에도 연결했습니다. 덕분에 어느 기기에서나 화면이 흔들리지 않고 똑같이 입력할 수 있습니다.

틀렸을 때 무엇이 틀렸는지 보여 주기

틀리면 정답과 내 입력을 위아래로 보여 주고, 자리마다 맞은 숫자는 초록색, 틀린 숫자는 빨간색으로 표시합니다. 앞부분은 맞고 뒷부분에서 틀렸는지, 두 숫자의 순서가 바뀌었는지를 바로 알 수 있어서 다음 판에 어떤 요령을 써야 할지 감이 옵니다.

정리

  • 연타 측정은 누르는 순간(pointerdown)을 센다.
  • 시간은 첫 입력부터, 끝난 뒤의 입력은 버린다.
  • 출제 규칙으로 너무 쉬운 문제를 거른다.
  • 모바일 입력은 시스템 키보드보다 직접 만든 키패드가 안정적이다.
