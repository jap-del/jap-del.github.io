에임 트레이너 개발기: 클릭 판정부터 오버슈팅 분석까지

개발기2026년 11월 10일 · 게임 허브

에임 트레이너는 겉보기엔 "동그라미를 누르는 게임"이지만, 공정하고 쓸모 있는 기록을 만들기 위해 몇 가지 장치를 넣었습니다. 이번 개발기에서는 그 과정을 정리합니다.

원형 과녁의 클릭 판정

과녁이 원이므로, 클릭한 점과 원 중심 사이의 거리가 반지름 이하이면 맞힌 것입니다. 제곱근 계산을 피하기 위해 양쪽을 제곱해서 비교합니다.

var dx = x - tx, dy = y - ty;
var hit = dx * dx + dy * dy <= r * r;

입력은 pointerdown 이벤트로 받습니다. 마우스 버튼을 누르는 순간, 화면을 터치하는 순간 바로 판정되므로 손을 떼는 시점의 차이가 기록에 섞이지 않습니다. 마우스 오른쪽 버튼은 무시하고, 우클릭 메뉴도 막아 두었습니다.

과녁 위치 고르기

과녁을 완전히 무작위로 놓으면 문제가 생깁니다. 바로 옆에 연달아 나오면 너무 쉽고, 화면 가장자리에 걸치면 일부가 잘려 보입니다. 그래서 두 가지 규칙을 두었습니다.

  • 가장자리에서 반지름 + 여백만큼 떨어진 곳에만 놓습니다. 위쪽은 시간 표시가 있으니 더 넉넉히 비웁니다.
  • 직전 과녁과의 거리가 화면 짧은 변의 25% 이상이 되도록, 조건을 만족할 때까지 최대 30번 다시 뽑습니다.

위치는 픽셀이 아니라 화면 크기에 대한 비율로 저장합니다. 게임 중 창 크기가 바뀌어도 과녁이 엉뚱한 곳으로 가지 않습니다.

과녁 크기와 기기 차이

과녁 반지름은 화면 짧은 변에 비례하되, 최소와 최대를 정해 두었습니다. 손가락 터치는 마우스보다 덮는 면적이 넓기 때문에, (pointer: coarse) 미디어 쿼리로 터치 기기를 감지해 최소 크기를 조금 키웠습니다. 같은 이유로 최고 기록도 PC와 모바일을 따로 저장합니다. 손가락과 마우스 기록을 한 줄로 비교하는 것은 공정하지 않기 때문입니다.

기록 계산

  • 시작: 가운데 시작 과녁을 맞힌 순간 performance.now()로 시간을 잽니다.
  • 과녁당 시간: 과녁이 나타난 시각과 맞힌 시각의 차이를 모아 평균을 냅니다.
  • 벌점: 빗나간 클릭 하나에 0.5초를 더합니다. 마구 누르는 전략을 막기 위한 장치입니다.
  • 정확도: 맞힌 클릭 ÷ 전체 클릭입니다.

탭을 벗어나면 그 판은 취소합니다. 다른 창을 보고 돌아온 시간이 기록에 들어가면 의미가 없기 때문입니다.

클릭 분포 그리기

맞힌 클릭마다 과녁 중심에서 얼마나 벗어났는지를 반지름으로 나눈 값으로 저장합니다. 과녁 크기가 달라도 같은 기준으로 비교할 수 있도록 정규화하는 것입니다. 결과 화면의 작은 그림은 이 값들을 하나의 과녁 위에 모아 찍은 것입니다. 평균 위치가 한쪽으로 치우쳐 있으면 "오른쪽 아래쪽으로 치우침"처럼 알려 줍니다.

오버슈팅 판별: 이동 방향으로 투영하기

단순히 "오른쪽으로 치우침"만으로는 감도 문제인지 알기 어렵습니다. 과녁이 매번 다른 방향에서 나오기 때문입니다. 그래서 직전 과녁에서 현재 과녁으로 향하는 방향을 기준으로, 클릭이 그 방향으로 중심을 지나쳤는지 못 미쳤는지를 계산했습니다.

// u: 이전 과녁 → 현재 과녁 방향
var ux = tx - px, uy = ty - py;
var len = Math.sqrt(ux * ux + uy * uy);
// 클릭 오차를 이동 방향으로 투영
var p = (dx * ux + dy * uy) / len / r;

p가 양수이면 이동 방향으로 더 나아가서 누른 것(오버슈팅), 음수이면 덜 가서 누른 것(언더슈팅)입니다. 이 값들의 평균이 반지름의 12%를 넘으면 결과 화면에 감도 조절 조언을 보여 줍니다. 벡터의 내적(투영)이라는 수학 개념이 게임의 피드백으로 바로 쓰이는 좋은 예입니다.

정리

기록 게임에서 중요한 것은 화려한 그래픽보다 공정한 측정과 쓸모 있는 피드백입니다. 완성된 결과는 에임 트레이너에서 직접 확인해 보세요. 비슷한 시간 측정 방식은 라이트 아웃 개발기에서도 다뤘습니다.

함께 읽으면 좋은 글

  • 피츠의 법칙: 작고 먼 버튼은 왜 누르기 어려울까
  • 마우스 감도, DPI, eDPI 쉽게 정리하기
  • 에임 실력을 올리는 연습법: 플릭, 트래킹, 그리고 자세
