모바일 브라우저에서도 잘 돌아가는 웹 게임 만들기: 6가지 체크리스트

개발기2026년 10월 19일 · 잽델 게임즈

점프잇과 라이트 아웃은 PC뿐 아니라 스마트폰 브라우저에서도 플레이하는 사람이 많습니다. 모바일에서 웹 게임을 쾌적하게 만들기 위해 챙긴 항목을 체크리스트로 정리했습니다.

1. click 대신 pointerdown으로 즉시 반응

모바일 브라우저의 click 이벤트는 손가락을 뗀 뒤에 발생합니다. 예전에는 더블 탭 확대 여부를 판단하느라 300ms 정도 늦게 오기도 했습니다. 타이밍이 중요한 게임에서는 치명적이지요.

점프잇은 화면에 손가락이 닿는 순간 발생하는 pointerdown 이벤트로 점프합니다. 마우스, 터치, 펜을 하나의 이벤트로 처리할 수 있다는 장점도 있습니다.

2. touch-action으로 더블 탭 확대 막기

게임 화면을 빠르게 연타하면 브라우저가 더블 탭 확대로 오해할 수 있습니다. 게임 영역에 CSS touch-action: manipulation을 지정하면 스크롤과 핀치 확대는 그대로 두고 더블 탭 확대만 꺼집니다. 페이지 전체의 확대를 막는 방식은 글을 읽기 어려운 사람에게 불편을 주기 때문에, 게임 영역에만 적용하는 것이 좋습니다.

3. 탭을 벗어나면 자동 일시정지

게임 중에 메시지 알림을 확인하러 다른 앱으로 갔다가 돌아왔는데 이미 게임 오버라면 억울하겠지요. visibilitychange 이벤트로 페이지가 숨겨졌는지 감지해서 게임과 음악을 멈추고, 다시 돌아오면 이어서 진행합니다.

document.addEventListener('visibilitychange', function(){
  if(document.hidden && state === 'playing'){
    state = 'paused';
  }
});

돌아왔을 때는 시간 기준값을 현재로 다시 맞춰야 합니다. 그렇지 않으면 자리를 비운 시간만큼 델타 타임이 커져 캐릭터가 순간이동합니다.

4. 브라우저 저장소는 실패할 수 있다고 가정

최고 기록과 설정은 localStorage에 저장합니다. 그런데 일부 브라우저의 사생활 보호 모드나 저장 공간이 꽉 찬 상황에서는 저장이 실패하면서 오류가 날 수 있습니다. 저장소를 읽고 쓰는 코드를 try/catch로 감싸 두면, 저장이 안 되더라도 게임 자체는 멀쩡히 돌아갑니다.

5. 화면 크기에 따라 배치 바꾸기

PC에서는 게임 양옆에 스킨 선택과 랭킹을 두고, 화면이 좁은 모바일에서는 게임을 맨 위에 두고 나머지를 아래로 내립니다. CSS 그리드의 영역 이름(grid-template-areas)을 쓰면 미디어 쿼리 하나로 배치를 깔끔하게 바꿀 수 있습니다.

6. 고해상도 화면과 성능의 균형

캔버스를 화면 배율(devicePixelRatio)에 맞추면 선명해지지만, 배율이 3인 휴대폰에서는 그려야 할 픽셀이 9배로 늘어납니다. 점프잇은 배율을 최대 2로 제한해 선명함과 프레임 속도 사이의 균형을 맞췄습니다. 자세한 내용은 게임 루프 개발기에 있습니다.
