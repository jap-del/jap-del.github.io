점프잇 개발기 ③: 음악 파일 없이 Web Audio API로 소리 만들기

개발기2026년 10월 19일 · 잽델 게임즈

점프잇의 배경 음악과 효과음은 음악 파일을 하나도 쓰지 않았습니다. 모두 브라우저의 Web Audio API로 그 자리에서 소리를 합성합니다. 파일을 내려받을 필요가 없어 로딩이 빠르고, 저작권 걱정도 없습니다.

소리의 재료: 오실레이터와 게인

Web Audio API에서 소리는 노드(node)를 연결해서 만듭니다.

  • 오실레이터(OscillatorNode): 정해진 주파수의 파형을 만들어 내는 소리의 원천입니다. sine(부드러운 소리), square(8비트 게임기 같은 소리), triangle(그 중간) 같은 파형을 고를 수 있습니다.
  • 게인(GainNode): 볼륨을 조절합니다. 시간에 따라 볼륨을 바꾸면 소리의 모양(엔벨로프)이 만들어집니다.

점프 효과음 만들기

점프 소리는 짧은 시간 동안 음이 올라가면서 빠르게 사라지는 소리입니다.

osc.type = 'sine';
osc.frequency.setValueAtTime(320, t);
osc.frequency.exponentialRampToValueAtTime(700, t + 0.1);
gain.gain.setValueAtTime(0.24, t);
gain.gain.exponentialRampToValueAtTime(0.001, t + 0.13);

0.1초 동안 320Hz에서 700Hz로 음을 끌어올리고, 볼륨은 0.13초 만에 거의 0으로 줄입니다. 위로 솟는 느낌이 소리에도 담기도록 한 것입니다. 게임 오버 소리는 반대로 세 음이 차례로 내려가게 만들어 "아쉬움"을 표현했습니다.

배경 음악: 미리 예약하는 스케줄러

배경 음악은 짧은 멜로디(8음)와 베이스를 반복 재생합니다. 이때 setTimeout으로 "다음 음을 지금 재생"하면 타이머가 조금씩 밀려서 박자가 흔들립니다.

그래서 오디오 시계(audioContext.currentTime)를 기준으로, 조금 앞의 미래에 연주할 음들을 미리 예약하는 방식을 썼습니다. 25ms마다 스케줄러가 깨어나 앞으로 0.12초 안에 연주할 음이 있으면 정확한 시각을 지정해 예약해 둡니다. 자바스크립트 타이머가 조금 늦게 깨어나도 실제 소리는 오디오 시계에 맞춰 정확한 박자로 나옵니다.

브라우저 자동 재생 정책

요즘 브라우저는 사용자가 페이지와 상호작용하기 전에는 소리를 자동으로 재생하지 못하게 막습니다. 그래서 점프잇은 오디오 시스템을 페이지가 열릴 때가 아니라 "게임 시작"을 누르는 순간 만듭니다. 사용자의 클릭이나 탭에 이어서 만들어진 오디오는 정상적으로 재생됩니다.

음소거와 설정 기억

도서관이나 지하철에서도 편하게 즐길 수 있도록 음소거 버튼을 넣었습니다. 음소거를 하면 전체 볼륨을 담당하는 마스터 게인을 0으로 부드럽게 내리고, 설정은 브라우저 저장소에 남겨 다음 방문 때도 유지됩니다.

탭을 다른 곳으로 옮기면 게임과 음악도 자동으로 멈춥니다. 이 부분은 모바일 웹 게임 최적화 글에서 다룹니다.

정리

  • 오실레이터 + 게인 조합만으로 간단한 게임 소리를 만들 수 있습니다.
  • 음 높이와 볼륨의 변화가 소리의 느낌을 결정합니다.
  • 배경 음악은 오디오 시계 기준으로 미리 예약해야 박자가 흔들리지 않습니다.
  • 소리는 사용자 입력 이후에 시작해야 합니다.

소리를 켜고 점프잇을 플레이하면서 박자에 맞춰 점프해 보세요.
