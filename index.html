  • 반응속도란 무엇일까? 측정 원리와 평균 기록

    반응속도(반응시간)의 뜻, 자극이 근육까지 전달되는 과정, 단순 반응과 선택 반응의 차이, 그리고 평균 기록을 정리했습니다.

  • F1 스타트 신호의 원리: '라이트 아웃'은 어떻게 진행될까

    F1 레이스 출발 신호가 진행되는 순서와 무작위 대기 시간의 의미, 드라이버에게 반응속도가 중요한 이유를 설명합니다.

  • 육상 100m의 부정출발 규칙: 왜 0.1초가 기준일까

    육상 단거리에서 출발 반응이 0.1초보다 빠르면 부정출발로 보는 이유와, 한 번만 부정출발해도 실격되는 현재 규칙을 알아봅니다.

  • 점프잇 개발기 ①: 캔버스와 게임 루프 만들기

    HTML5 캔버스와 requestAnimationFrame으로 브라우저 게임의 기본 뼈대인 게임 루프를 만드는 과정과, 화면 크기·고해상도 대응 방법을 설명합니다.

  • 점프잇 개발기 ②: 중력, 2단 점프, 그리고 관대한 충돌 판정

    점프잇의 점프 물리, 2단 점프 구현, 억울하지 않게 만든 충돌 판정, 시간에 따라 어려워지는 난이도 곡선을 설명합니다.

  • 점프잇 개발기 ③: 음악 파일 없이 Web Audio API로 소리 만들기

    오디오 파일 없이 Web Audio API의 오실레이터로 효과음과 배경 음악을 만드는 방법, 브라우저 자동 재생 정책 대응, 음소거 저장을 다룹니다.
